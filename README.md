# MARKET RAID

웹 기반 **2~4인 협동 전술 FPS**. 좁은 재래시장 실내에서 폭발물 2개를 해체하는 미션.
브라우저만 있으면 되고, **모바일(가로 모드) 전용 터치 조작**을 기본으로 만들었다.

```
┌─ 장르      1인칭 슈팅 + 협동 미션 (레디 오어 낫 풍 리얼리즘)
├─ 맵        남부 재래시장 실내동 15m × 11m (실제로 걸을 수 있는 바닥 60㎡)
├─ 인원      2~4인 협동 + 적 AI 봇 2~5명
├─ 목표      폭발물 2곳 해체 (제한시간 6분)
└─ 기술      Three.js r170 + Socket.io + Node/Express
```

## 1. 실행 방법

### 준비물
- **Node.js 18 이상** ([nodejs.org](https://nodejs.org) 에서 LTS 설치)

### 단계

```bash
# 1) 프로젝트 폴더로 이동
cd game33

# 2) 라이브러리 설치 (처음 한 번만, 약 30초)
npm install

#    게임만 돌릴 거라면 개발 도구를 빼고 더 가볍게 설치해도 된다
#    npm install --omit=dev

# 3) 서버 켜기
npm start
```

터미널에 이렇게 나오면 성공이다.

```
  ███  MARKET RAID  ███
  맵: 남부 재래시장 - 실내동  (15m x 11m, 충돌박스 29개)
  서버 준비됨 ->  http://localhost:3000
```

### 4) 접속

| 어디서 | 주소 |
|---|---|
| 서버를 켠 PC | `http://localhost:3000` |
| 같은 와이파이의 **폰/태블릿** | `http://<PC의 내부 IP>:3000` |

내부 IP 찾는 법:
- **Windows** → `ipconfig` → "IPv4 주소" (예: `192.168.0.10`)
- **Mac / Linux** → `ifconfig | grep "inet "` 또는 `ip addr`

폰에서 `http://192.168.0.10:3000` 처럼 입력하면 된다.
**폰은 가로로 눕혀야** 한다. 세로로 들면 "기기를 가로로 돌려주세요" 안내가 뜬다.

> **방화벽**: 접속이 안 되면 PC 방화벽에서 3000번 포트를 열어야 한다.
> 포트를 바꾸려면 `PORT=8080 npm start`.

### 5) 같이 하기

1. 한 명이 **"방 만들기"** → 5자리 코드가 나온다 (예: `9K7X7`)
2. 나머지가 그 코드를 입력하고 **"입장"**
3. 방장이 적 인원 / 난이도를 고르고 **"작전 개시"**

혼자 해보려면 메뉴에서 **"혼자 연습하기"** 를 누르면 바로 시작된다.

## 3. 미션 규칙

- 맵 안에 **폭발물이 2곳** 있다 (창고 동편 A / 서편 통로 B). 빨간 점멸등과 바닥 링으로 표시된다.
- 폭발물 **1.6m 안에서** 해체 버튼을 **누르고 있으면** 6초 만에 해체된다.
  - **둘이 같이 붙으면 더 빠르다** (협동 보상)
  - 손을 떼면 진행도가 서서히 되돌아간다
- 해체하는 순간 **맵의 모든 적이 그 위치로 몰려온다.** 한 명이 해체하는 동안 나머지가 지켜야 한다.
- **둘 다 해체하면 승리.** 팀 전멸 또는 6분 초과면 실패.
- 체력은 **자동으로 안 찬다.** 죽으면 그 판은 끝이다 (팀원이 이어서 해야 한다).

### 엄폐가 진짜로 동작한다
적의 시야/총알 판정이 **3D** 라서, 드럼통(0.99m)이나 상자(0.75m) 뒤에 **앉으면 실제로 안 보이고 안 맞는다.**
반대로 서 있으면 낮은 엄폐물 너머로 보인다. 통로가 1.4~1.6m 밖에 안 되므로 문틀을 천천히 꺾어 보는 게 유리하다.

## 4. 내 3D 모델로 바꾸기

### 4-1. 어디에 넣나

**`public/assets/models/` 폴더에 GLB 파일을 넣고 아래 이름으로 맞추면 끝이다.**
코드를 고칠 필요 없다.

| 파일명 | 무엇 | 현재 크기 |
|---|---|---|
| `stall-tarp.glb` | 천막 매대 (낮은 엄폐물) | 2.83 × 1.51 × 1.58 m |
| `stall-wood.glb` | 큰 나무 매대 (시야 차단) | 3.09 × 2.62 × 3.06 m |
| `crate.glb` | 나무 상자 | 0.75 × 0.75 × 0.75 m |
| `barrel.glb` | 드럼통 | 0.87 × 0.99 × 0.87 m |
| `vase.glb` | 항아리 | 1.02 × 1.53 × 1.02 m |
| `well.glb` | 우물 | 2.14 × 2.35 × 2.14 m |
| `table.glb` | 작업대 | 1.60 × 1.18 × 3.20 m |
| `rack.glb` | 벽면 진열대 | 0.39 × 1.90 × 1.78 m |
| `character.glb` | 사람 (팀원 + 적 공용, 색만 다르게 칠한다) | 키 1.80 m |
| `weapon-rifle.glb` | 돌격소총 M416 | 길이 0.90 m |
| `weapon-smg.glb` | 기관단총 UMP9 | 길이 0.65 m |
| `weapon-sniper.glb` | 저격총 AWM | 길이 1.20 m |

> **파일이 없어도 게임은 돌아간다.** 없으면 같은 크기의 박스/원기둥으로 자동 대체되고,
> 브라우저 콘솔에 `[assets] GLB 파일이 없어서 임시 도형으로 대체함: ...` 이 찍힌다.
> 나중에 파일을 넣으면 코드 수정 없이 바로 교체된다.

### 4-2. 크기/방향이 안 맞을 때 → `public/js/config.js`

**이 파일 하나만** 고치면 된다. 맨 위 `MODELS` 를 보면 된다.

```js
export const MODELS = {
  crate: {
    url: '/assets/models/crate.glb',   // ← 경로만 바꾸면 다른 파일을 쓸 수 있다
    scale: 1,                          // ← 너무 크거나 작으면 여기 (예: 0.5)
    rotY: 0,                           // ← 엉뚱한 방향을 보면 여기 (Math.PI = 180도)
    placeholder: { type: 'box', w: 0.75, h: 0.75, d: 0.75, color: 0x8a6b3f },
  },
  // ...
};
```

- **총이 뒤를 본다** → `rotY` 를 `Math.PI / 2` ↔ `-Math.PI / 2` 로 바꾼다
  (원본 3정은 모두 "총구가 -X" 라서 `-Math.PI / 2` 로 맞춰놨다)
- **사람이 뒤돌아 서 있다** → `character` 의 `rotY` 를 `0` ↔ `Math.PI` 로 바꾼다

> ⚠️ **크기를 바꿨으면 충돌 박스도 같이 고쳐야 한다.**
> 소품의 충돌 박스는 `public/js/map-data.js` 의 `PROPS` 안 `col: { w, d, h }` 이다.
> 안 고치면 **눈에 보이는 것과 몸이 막히는 곳이 달라진다.** 고친 뒤에는 꼭:
> ```bash
> npm run check:map
> ```

### 4-3. 1인칭 총 위치 맞추기 (제일 많이 손대는 부분)

**게임 중에 `V` 키**를 누르면 슬라이더 패널이 뜬다. 실시간으로 위치를 맞춘 뒤
**"config.js 에 붙여넣을 값 복사"** 를 누르면 그대로 쓸 수 있는 숫자가 복사된다.
그걸 `config.js` 의 `VIEWMODEL` 에 붙여넣으면 끝.

```js
export const VIEWMODEL = {
  rifle: { pos: [0.195, -0.170, -0.575], rot: [0.015, 0, 0], scale: 1.0,
           adsPos: [0.0, -0.104, -0.540], adsRot: [0, 0, 0] },
};
```

> **총이 화면을 가득 채운다면** `pos` 의 Z 값이 문제다.
> GLB 는 총의 *한가운데*가 원점이라 `-0.3` 같은 값을 주면 개머리판이 카메라 뒤로 넘어가서
> 총 내부가 보인다. **`z = -(총길이/2 + 0.1)`** 정도가 적당하다.

### 4-4. 원본 에셋에서 다시 굽기 (선택)

`assets-src/` 에 Sketchfab 원본(gltf + bin + textures)이 들어있다.
여기서 GLB 를 다시 구우려면:

```bash
npm run build:assets
```

`tools/build-assets.mjs` 가 하는 일:
1. `scene.gltf` 에서 **필요한 노드만** 잘라낸다 (`Well`, `M416_8`, `UMP9_7` …)
2. **발이 y=0, 중심이 원점**이 되도록 위치를 정규화
3. **목표 크기(m)에 맞춰 스케일** — 그래서 게임 코드에서 `scale` 을 만질 필요가 없다
4. 텍스처를 모바일용으로 축소 (1024 → 256/512), 안 쓰는 데이터 제거
5. 총기 팩에 섞여 있던 **형광 청록색 더미 머티리얼을 건메탈로** 교체

새 모델을 추가하려면 `tools/build-assets.mjs` 맨 위 `JOBS` 배열에 한 줄 추가하면 된다.

## 5. 모바일 성능 (iPhone 13 Pro 기준)

기본 품질은 **"높음"** 이고, 13 Pro 에서 60fps 를 목표로 잡았다.

| 프리셋 | 해상도 배율 | 그림자 | 그림자 해상도 | 시야 거리 | 전구 수 |
|---|---|---|---|---|---|
| 낮음 | 1.0× | ✗ | – | 24 m | 3 |
| 보통 | 1.25× | ✓ | 1024 | 32 m | 5 |
| **높음 (기본)** | **1.5×** | **✓** | **2048** | **45 m** | **8** |
| 최고 (PC) | 2.0× | ✓ | 4096 | 70 m | 8 |

- 13 Pro 의 실제 DPR 은 3 이지만 **1.5 로 제한**했다. 3 으로 그리면 픽셀이 4배라 프레임이 반토막 나는데, 6인치 화면에서는 눈에 띄는 차이가 거의 없다.
- **그림자를 만드는 광원은 딱 하나**(천장 평행광)다. 전구 8개마다 그림자를 켜면 모바일은 버티지 못한다. 나머지 전구는 색감만 담당한다.
- **자동 화질 조절**: 45fps 아래가 3초 이상 이어지면 한 단계 자동으로 내려간다. 설정에서 끌 수 있고, 직접 품질을 고르면 자동으로 꺼진다.
- 전체 GLB 용량은 **약 5.5MB** (모델 12개). 첫 로딩이 느리면 여기가 원인이다.
- 효과음은 **파일이 아니라 WebAudio 로 합성**한다. 받을 게 없어서 첫 로딩이 0초다.

설정을 바꾸려면 `public/js/config.js` 의 `QUALITY` 를 고치면 된다.

### 맵을 고칠 때

맵은 **`public/js/map-data.js` 한 곳**에만 있다. 서버와 클라이언트가 같은 파일을 읽으므로
여기만 고치면 벽·충돌·봇 경로·그리기가 한꺼번에 따라온다.

고친 뒤에는 **반드시**:

```bash
npm run check:map
```

이게 잡아주는 것:
- 소품이 벽에 박혔는지 / 소품끼리 겹쳤는지
- 스폰·순찰·해체 지점이 물체 안에 끼었는지
- **스폰에서 해체 지점까지 실제로 걸어갈 수 있는지** (반지름 0.35m 원으로 플러드 필)
- 해체 지점 주변에 설 자리가 있는지
- 통로 폭 리포트 + ASCII 미니맵

> 실제로 이 검사가 "드럼통 두 개가 매대 남쪽을 통째로 막아서 못 나가는" 버그와
> "창고 출입구가 하나뿐이라 해체 지점에 도달 불가" 를 잡아냈다. 눈으로는 절대 못 본다.

### 개발용 도구

```bash
npm start                # 서버
npm run check:map        # 맵 검사 (위 참고)
npm run build:assets     # 원본 → GLB 다시 굽기
npm run preview:assets   # GLB 12개를 4방향에서 렌더 → tools/dev/preview-out/*.png

# 아래 3개는 서버를 켜둔 상태에서 돌린다
node tools/dev/smoke-test.mjs        # 혼자 한 판 자동 플레이 (부팅~해체~교전까지)
node tools/dev/test-multiplayer.mjs  # 탭 2개로 방 코드 협동 검증
node tools/dev/check-viewmodel.mjs   # 총 3정 × 허리사격/정조준 = 6장 렌더

node tools/dev/inspect.mjs weapon-rifle   # GLB 실제 치수/방향을 숫자로 확인
```

`smoke-test` 가 검사하는 것: GLB 12개 로드 · 서버 연결 · 방 생성 · 매치 시작 ·
적 캐릭터 뼈대 15개 인식 · 걷기 애니메이션 · 사격/탄약 · 정조준 · 앉기 · 재장전 ·

`test-multiplayer` 가 검사하는 것: 방 코드 발급/입장 · 두 탭 로비 동기화 ·

## 7. 네트워크 구조

```
        ┌──────────── 서버가 진실 ────────────┐
클라이언트                                  서버 (20Hz)
   │                                          │
   │ ── input (20Hz, 내 위치/시점) ─────────▶ │ 충돌 재보정 (벽 뚫기 방지)
   │ ── shoot (방향만) ────────────────────▶ │ 3D 레이캐스트로 명중 판정
   │                                          │ 봇 AI 시뮬레이션
   │ ◀───────── snapshot (20Hz) ───────────── │ 전원 위치/체력/탄약/봇/목표
   │                                          │
   └─ 남의 캐릭터는 110ms 과거를 보간해서 그린다 (끊김 방지)
```

- **위치는 클라가 예측**하고 서버가 한 번 더 충돌 보정한다 → 조작이 즉각적이면서 벽은 못 뚫는다.
- **명중 판정은 100% 서버**가 한다. 클라는 "어느 방향으로 쐈다"만 보낸다.
- **적 AI는 전부 서버**에서 돈다. 모든 플레이어가 똑같은 적을 본다.
- 탄약·체력도 서버 값이 최종이다. 클라 표시는 스냅샷이 올 때마다 맞춰진다.

## 9. 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 폰에서 접속이 안 된다 | PC 방화벽에서 3000 포트 열기. PC 와 폰이 **같은 와이파이**인지 확인 |
| 화면이 까맣다 | 브라우저 콘솔(F12)에 WebGL 오류가 있는지 확인. 아주 오래된 기기는 미지원 |
| 소리가 안 난다 | iOS 는 **화면을 한 번 터치해야** 소리가 켜진다. 무음 스위치도 확인 |
| 프레임이 낮다 | 설정에서 화질을 "보통"/"낮음" 으로. 자동 조절이 켜져 있으면 알아서 내려간다 |
| 총이 화면을 가득 채운다 | `VIEWMODEL` 의 `pos` Z 값 문제 → 4-3 참고 |
| 벽이 없는데 몸이 막힌다 | 모델과 충돌 박스가 어긋난 것 → `map-data.js` 의 `col` 수정 후 `npm run check:map` |
| 임시 박스로만 나온다 | `public/assets/models/` 에 GLB 가 없다. 콘솔에 어떤 파일이 없는지 찍힌다 |
| 마우스가 안 잠긴다 | 게임 화면을 한 번 클릭하면 잠긴다. `Esc` 로 풀린다 |
